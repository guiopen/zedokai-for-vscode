# Zedokai for VSCode

A port of [zedokai](https://github.com/slymax/zedokai) themes to [Visual Studio Code](https://code.visualstudio.com/), based on the [Monokai Pro](https://monokai.pro/) color scheme.

## Themes

8 themes in total, covering all original filters with the refined dark palette adapted for VS Code, plus 2 light variations.

| Dark | Light variant |
|------|---------------|
| Zedokai | Zedokai Light |
| Zedokai Classic | Zedokai Light |
| Zedokai (Filter Machine) | Zedokai Light |
| Zedokai (Filter Octagon) | Zedokai Light |
| Zedokai (Filter Ristretto) | Zedokai Light |
| Zedokai (Filter Spectrum) | Zedokai Light (Filter Sun) |

### Included Variants
- **Zedokai** (Default)
- **Zedokai Classic**
- **Zedokai (Filter Machine)**
- **Zedokai (Filter Octagon)**
- **Zedokai (Filter Ristretto)**
- **Zedokai (Filter Spectrum)**
- **Zedokai Light**
- **Zedokai Light (Filter Sun)**

## Installation

### Via VS Code Marketplace
1. Open the Extensions view (`Ctrl+Shift+X` or `Cmd+Shift+X`).
2. Search for `Zedokai for VSCode`.
3. Click **Install**.

### Via Command Palette
Press `Ctrl+P` (or `Cmd+P`) and paste:
```text
ext install guiamaral.zedokai-for-vscode
```

### Activate Theme
1. Press `Ctrl+K Ctrl+T` (or `Cmd+K Cmd+T`).
2. Select your favorite **Zedokai** theme from the list.
